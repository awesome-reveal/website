# Awesome Reveal Docs

The docs site for the `@awesome-reveal/*` packages, at <https://awesome-reveal.dev>. The site uses [Starlight](https://starlight.astro.build).

The packages are in [awesome-reveal/awesome-reveal](https://github.com/awesome-reveal/awesome-reveal).

## Commands

Install pnpm 11 or later. pnpm downloads the Node and pnpm versions in `devEngines` of `package.json`, and runs the scripts with them.

| Command        | Action                                               |
| :------------- | :--------------------------------------------------- |
| `pnpm install` | Install the dependencies.                            |
| `pnpm dev`     | Start the dev server at `localhost:4321`.            |
| `pnpm build`   | Run `astro check`, then build the site to `./dist/`. |
| `pnpm preview` | Serve the build from `./dist/`.                      |
