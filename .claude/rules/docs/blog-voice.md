# Blog voice

Blog posts use plain, conversational English. This voice replaces the ASD-STE100 part of `site-copy.md`. The other parts of `site-copy.md`, `page-titles.md` and `content-sources.md` still apply.

A post speaks as its author to a developer. The [Google developer style guide](https://developers.google.com/style/tone) asks for a voice that is "conversational, friendly, and respectful without using slang", like "a knowledgeable friend".

- Write the body in the first person singular: "I rewrote", "tell me". One person writes and maintains the packages.
- Use everyday words, contractions and common phrasal verbs: "once", "it's", "set up".
- Keep most sentences short, and vary their length.
- Start with the news. Then tell the problem, the decision and the result. Give concrete numbers, and link to the docs for the details.
- Write each heading as a neutral topic with the search words, such as "Why Awesome Reveal 1.0 is a rewrite". Keep headings in the third person.

Readers of the blog come from many cultures and read English at different levels. Keep these parts of STE:

- the active voice
- the same term for each concept as the docs use
- literal words, with no idioms, slang or cultural references
