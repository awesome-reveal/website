title: Start with your AI agent
---

Add scroll reveal animations to this project with Awesome Reveal (https://awesome-reveal.dev).

1. Find the framework of this project, and choose its package:
   - React, Next.js: `@awesome-reveal/react`
   - Vue, Nuxt: `@awesome-reveal/vue`
   - Astro: `@awesome-reveal/astro`
   - Plain JavaScript or TypeScript, or another framework: `@awesome-reveal/core`
2. Install the package with the package manager of this project.
3. Read `skills/adding-reveal-animations/SKILL.md` in the installed package, and follow it. For more detail, read https://awesome-reveal.dev/getting-started.md.
4. Suggest elements to animate, such as headings, images and lists of cards. Ask me before you change the code.
5. Add the animations. Then run the type check, the lint, the tests and the build of the project.
6. Offer to install the skills of the package for later sessions, as https://awesome-reveal.dev/guides/ai-agents.md describes.
