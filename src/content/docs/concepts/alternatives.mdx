AOS, ScrollReveal and `react-reveal` also animate elements when they enter the viewport. This page compares them with Awesome Reveal. The data comes from the npm registry and from the package source code, in November 2026.

## Versions and licenses

| Library        | Last version | License                |
| -------------- | ------------ | ---------------------- |
| Awesome Reveal | 1.0.0, 2026  | MIT                    |
| AOS            | 2.3.4, 2018  | MIT                    |
| ScrollReveal   | 4.0.9, 2021  | GPL-3.0, or commercial |
| react-reveal   | 1.2.2, 2018  | MIT                    |

## Frameworks

| Library        | Frameworks                       |
| -------------- | -------------------------------- |
| Awesome Reveal | React, Vue, Astro and JavaScript |
| AOS            | JavaScript                       |
| ScrollReveal   | JavaScript                       |
| react-reveal   | React 15 and 16                  |

## Browser APIs

| Library        | Finds the elements with      | Animates with      |
| -------------- | ---------------------------- | ------------------ |
| Awesome Reveal | Intersection Observer        | Web Animations API |
| AOS            | `scroll` and `resize` events | CSS transitions    |
| ScrollReveal   | `scroll` and `resize` events | CSS transitions    |
| react-reveal   | Intersection Observer        | CSS animations     |

`react-reveal` uses `scroll` events in browsers without Intersection Observer.

## Motion

| Library        | Reduced motion                | Plays again on scroll   |
| -------------- | ----------------------------- | ----------------------- |
| Awesome Reveal | Shows the content immediately | No                      |
| AOS            | No support                    | Yes, by default         |
| ScrollReveal   | No support                    | With the `reset` option |
| react-reveal   | No support                    | No                      |

"No support" means that the package source code does not read `prefers-reduced-motion`.

## AOS

[AOS](https://www.npmjs.com/package/aos) reads the animation from `data-aos` attributes in the HTML, such as `data-aos="fade-up"`. Its stylesheet hides the elements, and its script adds a class that starts a CSS transition. Version 3 is a beta, from October 2018.

## ScrollReveal

[ScrollReveal](https://www.npmjs.com/package/scrollreveal) reveals the elements that a CSS selector selects, with options in JavaScript. It sets the start state and the transition in inline styles. The GPL-3.0 license applies to compatible open source projects and to non-commercial use. To keep the source code of a commercial project private, buy a [commercial license](https://scrollrevealjs.org/pricing/).

## react-reveal

[`react-reveal`](https://www.npmjs.com/package/react-reveal) gives one React component for each effect, such as `Fade` and `Zoom`. It has exit animations. To move to Awesome Reveal, see [Migrate from react-reveal](/guides/migrate-from-react-reveal/).

`react-reveal` is not `react-awesome-reveal`. To migrate from `react-awesome-reveal`, see [Migrate from v4](/guides/migrate-from-v4/).

## Awesome Reveal

Awesome Reveal plays each entrance one time, and has no exit animations. To play an entrance again, use [`when`](/guides/manual-control/#play-the-entrance-again). For the browser APIs that it uses, see [How it works](/concepts/how-it-works/). For reduced motion, focus and screen readers, see [Accessibility](/concepts/accessibility/).
