## Hidden in the server HTML

- `data-awesome-reveal="hidden"` and `"cascade"`, and the `reveal.css` stylesheet.

## The 5 second fallback

- The `awesome-reveal-hold` animation. Unattached content shows after 5 seconds.
- No hold with `scripting: none` or reduced motion.

## Core does not hide content

- The server markup shows, then animates when `reveal()` runs.

## Search engines

- The content is in the HTML.
