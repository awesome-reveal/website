## Animations on the compositor

- The generated entrance. `blur` and additive keyframes run on the main thread in Chromium.

## Properties for your keyframes

- Animate `opacity`, `transform`, `translate`, `scale` and `rotate`. Avoid layout properties.
- Do not add `will-change`.

## Bundle size

- Core has no dependencies. Check the size claim against the tree-shaking test.

## Long lists

- Use one `Reveal` for each item, not a long cascade.
