## Server Components

- `Reveal` and `Cascade` are Client Components. Server Components pass serializable props, keyframes included.
- No `onReveal` or callback `ref` from a Server Component.

## Client Components

- The hooks, `when` and `onReveal`.

## App Router

- No setup with Turbopack.

## Pages Router with webpack

- Add `transpilePackages: ["@awesome-reveal/react"]`.

## Hydration

- Hydrate eagerly. After 5 seconds the content shows, then hides until it reveals.
