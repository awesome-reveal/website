## When to use an island

- Use `@awesome-reveal/astro` for Astro markup. Use the framework package inside a React or Vue island.

## Import the stylesheet

- `@awesome-reveal/react/reveal.css` or `@awesome-reveal/vue/reveal.css` in the page or layout.

## Hydrate with client:load

- Not `client:visible`: the content shows, then hides again.
