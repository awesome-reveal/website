## Reveal

- Props, `as`, `ref`, the other props go to the element.

## Cascade

- `Reveal` props plus `interval`.

## useReveal

- Options, returns `RevealState`.

## useCascade

- Options with `interval`.

## RevealState and getProps

- `revealed`, `getProps()`. `getProps` does not merge `style`.

## Types

- `RevealProps`, `CascadeProps`, `RevealOptions`, `CascadeOptions`, `RevealState`, `RevealTargetProps`, `Side`, `StartState`.

- `@awesome-reveal/react/reveal.css` for Astro islands.
