The two browser APIs that [Awesome Reveal uses](/concepts/how-it-works/) are [Baseline Widely available](https://developer.mozilla.org/en-US/docs/Glossary/Baseline/Compatibility).

For the Node.js and framework versions, see [Requirements](/getting-started/#requirements).

## Browsers

All packages support these browsers, or later versions:

| Browser       | Version |
| ------------- | ------- |
| Chrome        | 104     |
| Edge          | 104     |
| Firefox       | 74      |
| Safari        | 14.1    |
| Safari on iOS | 14.5    |

## Features with other versions

Some features need a later version, or are not available in all supported browsers:

- **Keyframes with `composite`**: see [Keep the element's own values](/guides/keyframes/#keep-the-elements-own-values).
- **`linear()` easing**: see [Set the easing](/guides/keyframes/#set-the-easing).
- **Keyframes with implicit start values**: see [Give explicit values to the first keyframe](/guides/keyframes/#give-explicit-values-to-the-first-keyframe).
- **The `scripting` media feature**: see [When the stylesheet does not hide content](/concepts/server-rendering/#when-the-stylesheet-does-not-hide-content).

## Older browsers

In a browser without one of the two APIs, the content does not stay hidden:

- Without the Intersection Observer API, the entrance plays immediately.
- Without [`Element.animate()`](https://developer.mozilla.org/en-US/docs/Web/API/Element/animate), the content shows with no animation.

The packages need no polyfill.
