Awesome Reveal animates elements when they scroll into view. Each framework package uses the same core. The core uses the [Intersection Observer API](https://developer.mozilla.org/en-US/docs/Web/API/Intersection_Observer_API) and the [Web Animations API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Animations_API) of the browser, and it has no dependencies.

## Requirements

| Framework  | Framework version | Node.js        |
| ---------- | ----------------- | -------------- |
| React      | 18 or 19          | 20.19 or later |
| Vue        | 3.5 or later      | 20.19 or later |
| Astro      | 6 or 7            | 22.12 or later |
| JavaScript |                   | 20.19 or later |

The packages are ES modules only. They include their TypeScript types.

## Install the package

Install the package for your framework.

<FrameworkTabs install />

With npm, yarn or bun, use `npm install`, `yarn add` or `bun add`, followed by the package name.

## Reveal an element

Wrap the element in `Reveal`. With `@awesome-reveal/core`, call `reveal()` with a CSS selector, an element or a list of elements.

<FrameworkTabs
  react={revealReact}
  vue={revealVue}
  astro={revealAstro}
  js={revealJs}
/>

When the element enters the viewport, it [fades in and moves up 24 pixels](/guides/entrances/#slide-in-from-a-side). The entrance [plays one time](/guides/manual-control/#play-the-entrance-again). You do not import a stylesheet.

## Animate a list

[`Cascade`](/guides/lists/) reveals its direct children one after the other. The [`interval`](/reference/options/#interval) option sets the time between the start of two children, in milliseconds. The default is 80.

<FrameworkTabs
  react={cascadeReact}
  vue={cascadeVue}
  astro={cascadeAstro}
  js={cascadeJs}
/>

## What happens when the page loads

- The React, Vue and Astro packages render the element as hidden in the server HTML, so the element does not flash before the script runs. If the script does not run in 5 seconds, the content shows.
- Hydrate the reveal content eagerly. With lazy hydration, the script can run after 5 seconds. Then the content shows, and hides again until it reveals.
- `@awesome-reveal/core` does not hide content before your script calls `reveal()`.
- If the user asks for [reduced motion](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion), the content shows at once, with no animation.
- If the browser does not support the Intersection Observer API or the Web Animations API, the content shows at once.

<Aside type="caution" title="React or Vue in an Astro island">
  Hydrate the island with `client:load`, not `client:visible`. Import
  `@awesome-reveal/react/reveal.css` or `@awesome-reveal/vue/reveal.css` in the
  Astro page or layout.
</Aside>
