## Reveal the items one after the other

- `Cascade`, `useCascade`, `v-cascade` and `cascade()` in framework tabs, with a live demo.
- Only the direct element children animate.

## Change the interval

- `interval` in ms, default 80. Child `index` waits `delay + index * interval`.
- A negative interval starts each later child further into its entrance.

## Reveal the words of a heading

- Wrap each word in an element with `display: inline-block`.

## Reveal a long list or a tall grid

- A cascade schedules all children at once. Wrap each item in `Reveal` instead.
