React, Vue and Astro tell your code when an element reveals. `@awesome-reveal/core` has no callback.

## Run code when the reveal starts

Each package gives the revealed element in a different way:

- React: the `onReveal` prop.
- Vue: the `reveal` event of `Reveal` and `Cascade`, and the `onReveal` option of `v-reveal` and `v-cascade`.
- Astro: a `reveal` DOM event. It comes from the rendered tag and bubbles.

<FrameworkTabs react={onRevealReact} vue={onRevealVue} astro={onRevealAstro} />

The code runs one time for each reveal, when the reveal starts. In a cascade, it gets the container.

- It also runs when no entrance plays, for example with reduced motion, or when focus shows a waiting element.
- In React, it runs one time also in StrictMode.
- After `when` becomes `false`, the next reveal runs it again. With reduced motion, the element does not reset, so the code does not run again.

## Wait for the end of the entrance

The entrance is a set of Web Animations on the element. To wait for its end, wait for the `finished` promises of these animations:

```js
function entranceFinished(element) {
  return Promise.all(
    element
      .getAnimations({ subtree: true })
      .map((animation) => animation.finished),
  );
}

// In the reveal callback:
entranceFinished(element)
  .then(() => element.classList.add("entered"))
  .catch(() => {});
```

- The promise rejects when the entrance stops early, for example after `when` becomes `false` or an unmount. Catch the rejection.
- The promise resolves immediately when no entrance plays, for example with reduced motion.
- The promise also waits for your own animations of the element and its descendants.

A waiting entrance is a paused animation, and a paused animation does not finish. If your code waits for all of `document.getAnimations()`, skip the animations with `playState === "paused"`.

## Read the revealed state

React and Vue give a `revealed` value that is `true` after the reveal. In Astro, the `awesome-reveal` host element has a `revealed` property.

<FrameworkTabs react={revealedReact} vue={revealedVue} astro={revealedAstro} />

In React, `useReveal` animates your own element with no wrapper. Spread `getProps()` on one DOM element.
