## Run code when the reveal starts

- React `onReveal`, Vue `@reveal` and the directive `onReveal` option, Astro `reveal` event that bubbles from the rendered tag.
- Runs one time for each reveal, also with reduced motion or focus.
- Core has no callback.

## Wait for the end of the entrance

- `Promise.all` of `element.getAnimations({ subtree: true })` finished promises.
- Catch the rejection when the entrance stops early.

## Read the revealed state

- React `useReveal().revealed`, Vue slot prop `revealed`, Astro host `revealed` property.
