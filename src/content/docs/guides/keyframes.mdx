## Give native keyframes

- Example: the bounce-in keyframes with a cubic-bezier easing, in framework tabs.
- `from` and `keyframes` cannot be used together.

## Set the easing

- Put the easing on the keyframes. No option sets it.

## End at the resting style

- The animation has no forwards fill, so the last keyframe must match the resting style.

## Keep the element's own values

- Use a neutral additive keyframe, such as `{ opacity: 0, composite: "add" }`.
- Needs Firefox 80 or Safari 16. Chromium runs additive keyframes on the main thread.

## Give explicit values to the first keyframe

- WebKit bug 212409.

## Animate custom properties

- The type accepts custom properties, such as `"--progress"`.
