Three options set when the entrance plays and how long it takes: `duration`, `delay` and `threshold`.

## Change the duration

`duration` sets the duration of the entrance, in milliseconds. The default is 600.

## Delay the entrance

`delay` sets the time between the reveal and the start of the entrance, in milliseconds. The default is 0. The element keeps its start state during the delay.

In this example, the title takes 800 milliseconds. The text starts 200 milliseconds after its reveal, so it starts after the title:

<FrameworkTabs
  react={delayReact}
  vue={delayVue}
  astro={delayAstro}
  js={delayJs}
/>

Keep `delay` below about 300 milliseconds. A long delay makes content appear late when the user scrolls quickly. Focus during the delay does not make the entrance start earlier.

## Reveal later with a threshold

`threshold` sets the visible fraction of the element that reveals it, from 0 to 1. The default is 0, so the element reveals when its first pixel enters the viewport. With 0.5, the element reveals when half of it is visible:

<FrameworkTabs
  react={thresholdReact}
  vue={thresholdVue}
  astro={thresholdAstro}
  js={thresholdJs}
/>

A change to `threshold` applies immediately in React, Vue and Astro. A change to `duration` or `delay` applies at the next reveal.

### Tall elements and small scroll containers

- If the viewport is too small to show the threshold fraction of the element, the element reveals when it enters the viewport.
- In a scroll container that is too small, the element reveals when it leaves the visible area of the container.

Keep the default threshold for tall elements and for long cascades.

### The start state moves the box that the threshold uses

A start state with `opacity: 0`, such as each side, waits at the resting position of the element. Other start states and your own keyframes wait at their first keyframe. Their offset, scale and rotation change the box that the viewport check uses. For example, with the start state `{ y: 80 }`, the element waits 80 pixels lower, so it reveals later.
