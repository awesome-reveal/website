## Change the duration

- `duration` in ms, default 600.

## Delay the entrance

- `delay` in ms, default 0. The element keeps its start state during the delay.
- Keep it below about 300 ms.
- Example: a title, then the text after it.

## Reveal later with a threshold

- `threshold` from 0 to 1, default 0.
- Tall elements and too small scroll containers.
- Live demo with two thresholds.
